# L'unione fa la cocchia

Gioco da browser: fai cadere le cocchie (i gusci, in ascolano) nel barattolo. Due cocchie uguali che si toccano si fondono in quella più grossa. Si vince arrivando alla Cocchia d'oro, si perde se il barattolo si riempie.

Gioca: https://g95g95.github.io/unione-fa-la-cocchia/

## Le cocchie

1. pistacchio
2. arachide
3. nocciola
4. mandorla
5. castagna
6. noce
7. uovo
8. vongola
9. cozza
10. lumaca
11. riccio di mare
12. granchio
13. cocco
14. tartaruga
15. Cocchia d'oro

## Com'è fatto

Un solo file, `index.html`: nessuna installazione e nessun server. Record e partita in corso restano nel browser di chi gioca.
